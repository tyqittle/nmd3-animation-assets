## 区分“真梗”和“自己编的”

- **高**：可在攻略、官方社区、剧情页或真实二创页面直接看到该梗/机制/设定。但“高”仅代表**出处明确**，不代表流行度排行，也不保证玩法当前仍适用。
- **中**：来源支持相关情境或个别玩家二创，尚不足以宣称全体玩家熟知；创作前可进一步考证。
- **创意**：原创二创提案，**不是**玩家社区已广泛传播的现成梗；勿伪称官方剧情或原台词。
- 「玩家黑话」是游戏圈术语，并非都天然好笑；库中的 `hook` 和 `shot` 才是把它拍成段子的方式。
- 2023—2025 年的玩法与抽卡机制有时效性，创作前请再核实最新版本。

**[2026-10-21 最新热点与 33 条新增方向](HOTSPOTS_2026-10-21.md)**：含跨圈热梗、忍3 10 月官方/玩家话题、原创联动，附截止时间及核实来源。

**[10 个短视频即用原创分镜](SHORT_VIDEO_SEEDS.md)**：每个提供约 8–15 秒的镜头、台词和节奏安排。

## 直接用于视频制作

1. 先在 [检索网页](index.html) 选梗，可以按类别、证据级别和角色搜索。
2. 读 `context` 避免用错背景，读 `hook` 获取笑点，读 `shot` 当作简易分镜。
3. 切回仓库 [角色素材目录](../assets/characters/) 和 [背景](../assets/backgrounds/) 选择适合的图片；不要默认图片已去背或适合骨骼动画。
4. 结合 [动画制作规范](../docs/ANIMATION_GUIDE.md) 输出新镜头；不要搬运视频原片、UP主水印梗图或配音。
5. 想要做典型忍3味的作品，优先使用 **姚化火扇、顺拐狐、麦当劳联赛、CC、追梦、三拖二、血影等隼白、小黑一拳、洛青吸欧气**；这些都有可核对的出处。

## 字段说明

`id` 唯一编号；`category` 素材类别；`characters` 角色/主体；`context` 真实出处概述；`hook` 可改编的笑点文案；`shot` 视频剪辑建议；`sources` 外部原始资料；`evidence` 为出处强弱标注；`asset_status` 区分链接与本地素材。

## 版权和事实核查

第三方梗图、视频、配音**只提供原始网址，未复制入库**。若之后确实需要收藏到仓库，应先核实原作者许可、授权范围和具体资产。原创镜头、字幕、脚本可单独制作。引用老视频或玩家陈述时避免误称“官方证实”。参见 [素材权利说明](../docs/RIGHTS.md)。
