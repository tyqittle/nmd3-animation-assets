# 《焚天：命中率靠缘分》｜忍村兵器广告恶搞

这是 **独立的 9:16 竖屏短片**，不是复盘会/采访的换皮，不复用旧对话框、固定座位、角色讲话轮换或固定片头。

## 独立创作设计

- 时长 24 秒，720 × 1280、24fps；音画由本项目 `render.py` 自行生成。
- 0–2.5 秒：仿华丽电视广告，忍村兵器台推出焚天。
- 2.5–6.8 秒：武器动态旋转、放大、环形光效；口号“气势拉满”。
- 6.8–10 秒：现实战斗测试，锁定骸骨死神。
- 10–13.5 秒：火焰武器飞行轨迹在屏幕上真实移动并突然拐弯躲过目标。
- 13.5–16.4 秒：音乐断拍，Boss呆住，漫画式惊讶大字和静止镜头。
- 16.4–20.4 秒：荒诞“最佳闪避奖”颁奖礼，完全虚构战斗数据。
- 20.4–24 秒：小黑出场收尾“它至少躲得很帅”。

**二创说明：** 焚天、骸骨死神和小黑图像取自仓库本地素材；“命中率”“闪避奖”和战斗演出皆为原创荒诞剧情，并非游戏武器真实机制或数值；没有素材就拒绝渲染，不能替换成方块人或与角色不对应的素材。

## 可重复渲染

```bash
python ninja/video/workflow/scripts/production.py --project video/projects/fentian-ad-parody/project.json --stage all
```

预览为 3 秒的低分辨率版本；正式片 24 秒，含自合成音乐/节奏声效与四句 AI 普通话旁白。保留独立的镜头程序，通用流程仅审核制作和交付。
