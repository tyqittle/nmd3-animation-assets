# 《小椒卖焚天：百炼烧心，焚天不烧心》

2026-10-21 重制版。这次真正遵循原热梗：**图便宜 → 用着烧心 → 回到贵货摊 → 顾客夸“贵是贵了点，但用着不烧心” → 老板一本正经讲规矩**。旧版“焚天烧了店铺，所以只烧铺子不烧心”的字面反转已经废弃。

视频为 9:16，720×1280、24fps、37秒荒诞兵器铺短剧；不是静态海报PPT。

## 机制核对与边界

| 对比项 | 百炼 | 焚天 |
|---|---|---|
| 释放方式 | 抛锤后回旋，接回后可继续蓄力出二段 | 第一段前方戳刺、定身；第二段击飞、重劈、终结戳刺 |
| 操作门槛 | **非双焰·小椒**使用要主动接回；双焰·小椒可自动接回 | 没有百炼式回锤接取环节 |
| 蓄力要求 | 接回后在地面/绳面蓄力1.5秒，满蓄力再出手能提高伤害 | 分段点击衔接技能，无百炼式回锤蓄力 |
| 生存与控场 | 定身和持续伤害；本片不作无证据的无敌差评 | 两段释放均有**短暂无敌**，还有定身和连续爆发 |

重要说明：**百炼不是弱武器**，本片表达小黑不熟悉百炼操作时的挫败感，不比较两武器绝对伤害、系数、官方价格或保值率。“百炼便宜，焚天贵”只是架空忍村商铺的戏剧价格。

## 如何制作

GitHub Actions 中使用 Ninja 3 Video Production 工作流并提供本项目 project.json 路径，或在仓库与音乐库的父目录运行如下命令：

    python ninja/video/workflow/scripts/production.py --project video/projects/xiaojiao-fentian-shop/project.json --stage all

动作、音效与音乐由项目独立合成。中文 AI 配音优先走 Edge TTS，出现失败时会记录在输出 JSON，绝不把只有字幕的片子冒称为配音完整。渲染和质检将产出 MP4、8帧质检图与声音报告。工作流只负责执行，不固定视频类型和排版。
