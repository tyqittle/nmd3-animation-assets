# 小椒卖焚天：贵是贵了点，但不烧心

> 2026-10-21 原创忍3二创搞笑短片；22.5秒，720×1280，24fps，H.264/AAC。

## 核心反转

小黑走进忍村小椒兵器铺，嫌新武器焚天贵。小椒承诺「贵是贵了点，但不烧心」。小黑当场试用，结果火势惊人，烧掉了店。小黑质疑承诺，小椒淡定回复「只烧铺子，不烧心」，售后小字「本店不包重建」。

自合成原创节拍和音效，中文配音优先使用 Edge TTS：旁白云扬、小黑云希、小椒晓晓。对话每句有固定时间窗口；音轨通过剪辑时长与响度约束，句子过长或者TTS失败将跳过该句，报告会明确列出，不会把不完整配音谎称完整成功。全片中文字幕始终可理解剧情。

## 运行方法

在克隆仓库的父目录中：

~~~bash
python ninja/video/workflow/scripts/production.py --project video/projects/xiaojiao-fentian-shop/project.json --stage all
~~~

或者在 GitHub Actions 中运行 **Ninja 3 Video Production**，填写该项目 manifest 的相对路径。渲染产生 MP4、技术校验截图（contact sheet）和素材/语音日志（JSON），全部放入该次 Actions Artifact（保留30天）。该独立项目服从通用工作流的质量检查，但不被其他视频的视觉模板限制。

项目视频属于忍3玩家二创，仅供个人欣赏及研究。游戏角色和武器的原始版权不因收录仓库而改变。
