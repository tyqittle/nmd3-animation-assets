# 《焚天：命中率靠缘分》2.5D镜头重制版

与初版为**两个不同的影片构建**，并非把老 MP4 放大重编码。本版独立镜头代码位于 [cinematic.py](../fentian-ad-parody/cinematic.py)，它使用仓库已核对的实图进行多层镜头、运动轨迹、速度线、光斑、镜头冲击、短暂凝固与转场变化。

## 本次重点的实质升级

- 视觉：真正按时间变化的武器飞行曲线，不是 8 张长镜头静态图的缩放；Boss 由远景推向近景，动画含景深背景、前后分层、斩击拖尾、光点与运动震动。
- 叙事：把视觉节奏收紧到 9 组明确的段落，开场近景→武器产品展示→小黑出击→Boss进场→发射→拐弯反转→战术性撤退→“最佳闪避奖”→小黑吐槽。
- 声音：从音乐库使用已入库的战斗乐曲、从零合成击打/划空音效、以戏剧性断音乐造反转；4 句中文AI旁白，并对音量动态压低背景音乐。
- 输出：1080×1920，30FPS，视频 CRF17（高清质量取向）+ AAC 192kbps。试片为 432×768，12FPS，用于快速检查镜头。

**重要限制：** 原图是静态立绘，不是骨骼模型；本作仍是手工程序化 2.5D 合成，不能把它称为真正的角色逐帧动画、原角色配音或图生视频。音乐版权/公开发布许可仍需复核。

## 单片质量验收

- 逐镜头确认：武器真的沿轨迹动、Boss不误识别、小黑不被裁断、没有用假人占位、结尾反转表达成立。
- 自动：音视频均存在，时长24秒，尺寸至少1080×1920，输出文件非空；视频能正常解码。
- 人工：检查压缩伪影、中文字幕、安全区域、配音字句和BGM是否掩盖对白。
- 只有通过本片验收才给最终下载；如果缺素材或TTS失败不默默用方块图占位。

制作命令（工作区包含`ninja/`与`music/`）：

```bash
python ninja/video/workflow/scripts/production.py --project video/projects/fentian-cinematic/project.json --stage all
```
