# 忍3素材实图纠错清单 · 2026-10-21

## 这轮究竟修了什么

之前只看文件名、来源页面与图片尺寸就判定分类，没有把实际图片内容纳入校验；因此出现「一张全幅宣传图被当作角色皮肤」「觉醒后获得的皮肤被当作忍者流派」「画面造型与来源名称可疑」等问题。

本轮直接从 GitHub 仓库读取指定图片、观察实际画面，并参考 BWIKI 的皮肤资料。**重点核对并纠正了 15 条元数据**，其中 **3 条标成 `review_status=quarantined`，不再进入默认图鉴**。其余尚未逐张验收，`visual_review=pending` 不能理解为「身份已核实」。

## 今后防止重犯

- [忍者立绘采集脚本](../scripts/discover_wiki_art.py) 增加透明画布检查：完整海报、完全不透明的宣传图**不能以独立角色立绘名义入库**。
- [皮肤采集目标表](../catalog/wiki_illustration_targets.json) 把已查证的流派觉醒外观与皮肤分开；未确认的走待核对。
- [素材图鉴](../index.html) 默认隐藏 `review_status=quarantined`，但为透明起见保留查看入口。
- [分类校验脚本](../scripts/validate_taxonomy.py) 增加数据与 CSV 的隔离状态检查，避免后续自动采集覆盖错误。

## 仍需做的事

还有大量原图只有名称与来源级别的校验，未逐张视觉审查。之后应逐个比对 **BWIKI 中清晰标注的原图、实图像素内容、角色/服装/流派归属、裁切和水印**，有问题的先隔离，找到精确对应后再解除隔离。若来源只是第三方新闻的营销配图，不可标成独立可分层立绘。
