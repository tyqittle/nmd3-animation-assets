# 忍者必须死3 · 动画素材库

为后续代码制作动画/MV 整理《忍者必须死3》的角色、Boss、武器与场景参考素材。

## 当前进度

- 已整理 **26 条图片来源记录**：角色 12、Boss 6、武器 1、场景 7。
- 图片来源、直链、分类及后续动画用途见 [catalog/assets.json](catalog/assets.json)。
- **这些是待下载的素材记录，不是已经保存的 26 张图片。** 不要把目录中的空文件夹误认为已入库。
- 可用 Python 下载、审计图片，生成本地图鉴；下载成功后才能称为素材入库。
- 仓库目前是 **Public**。游戏角色、美术、音乐属于原权利人。源文件的重新公开分发、商用使用需要确认授权。

## 目录规划

| 路径 | 内容 |
|---|---|
| `catalog/assets.json` | 素材主索引（ID、名称、直链、来源、分类、预期本地路径） |
| `assets/characters/` | 角色立绘、皮肤 |
| `assets/bosses/` | 怪物与 Boss |
| `assets/weapons/` | 武器、道具 |
| `assets/backgrounds/` | 壁纸和场景背景 |
| `assets/fx/` | 动画特效图层 |
| `scripts/fetch_assets.py` | 根据索引下载图片，并做基本格式校验 |
| `scripts/audit_assets.py` | 核对是否存在、是否是合法图片、查找重复 |
| `docs/RIGHTS.md` | 使用与版权说明 |

## 后续制作动画的标准

优先搜集高清、角色完整、干净背景/透明底的立绘。只把网页预览或角色头像标注为参考素材，不冒充全身立绘。素材下载后需核查尺寸和内容再做角色分层、关键帧、镜头运动与粒子特效。
